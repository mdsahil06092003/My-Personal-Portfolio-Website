# Md Sahil Alam — Portfolio Website

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a public repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` to the repository root and commit the changes.
3. In the repository, open Settings → Pages and ensure deployment from the `main` branch / root is selected if prompted.
4. Wait for deployment. Your URL will be `https://YOUR-USERNAME.github.io/`.

## Before publishing
- Replace `YOUR_EMAIL@example.com` with your email.
- Replace generic LinkedIn/GitHub links with your actual profile links.
- Add your real project repository and demo URLs.
- Keep only skills and project features you can confidently explain in an interview.
